# Foxes Finance

Foxes Finance is a learning project to build a football club financial intelligence platform. It will begin with Leicester City as a focused case study and gradually develop into a platform for analysing the financial health and investment profile of football clubs.

The intended analysis includes revenue, costs, wages, squad economics, valuation, and investment scenarios. This is an engineering-learning project, not investment advice.

## Why Leicester City?

Leicester City provides a concrete starting point for turning broad financial questions into a focused data and engineering problem. Beginning with one club keeps the first models, data decisions, and analysis questions manageable, while leaving room to extend the platform to other clubs later.

## Current phase

**Project 1 — Foundation**

This phase establishes the project context, the repository entry point, and sensible ignore rules. No application code, databases, Dockerfiles, infrastructure, or datasets are being created yet.

## Learning roadmap

The project will introduce its technology stack progressively, when each tool is useful for a real project need:

1. Python for data handling and analysis
2. SQL and PostgreSQL for structured financial data
3. Linux, networking, security, Git, and GitHub for engineering fundamentals
4. Docker and CI/CD with Jenkins for repeatable delivery
5. AWS, Terraform, and Ansible for cloud and infrastructure automation
6. Kubernetes for orchestration
7. AI and ML for advanced analysis and forecasting

## Future milestones

- Define the first financial questions and trustworthy data-source rules.
- Set up a minimal Python development environment and a small, explained data exercise.
- Design a PostgreSQL data model for club financial information.
- Load and validate initial financial and squad data.
- Produce a first repeatable financial analysis or report.
