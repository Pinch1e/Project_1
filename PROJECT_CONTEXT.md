# Foxes Finance — Project Context

## Project name

Foxes Finance

## Purpose

Build a football club financial intelligence platform using Leicester City as the initial case study.

## Business objective

Analyse club finances, wage structure, revenue, costs, squad economics, valuation, and investment scenarios. The platform will eventually support structured, evidence-led exploration of the financial factors behind a football club's performance and potential.

## Learning objective

Use this project to progressively learn:

- Python
- SQL and PostgreSQL
- Linux
- Networking
- Security
- Git and GitHub
- Docker
- AWS
- Terraform
- Ansible
- Jenkins and CI/CD
- Kubernetes
- AI and ML


## Project 1 scope — Foundation

Project 1 is limited to establishing the project documentation and repository hygiene needed for later work. It does not include application code, databases, Dockerfiles, infrastructure, or datasets.

## Business Questions

- What is Leicester City's annual revenue?
- What does Leicester City's scouting/recruitment network look like?
- How profitable could Leicester become over the next five years?
- What is Leicester City's annual operating cost?
- What are Leicester City's annual overheads?
- How sustainable is Leicester's wage bill relative to revenue?
- What could Leicester realistically be worth to an investor?
